# Auth Microservice

## About
This is the code generated for my bachelor's thesis, and is generated by Gemini, for the comparison with different models, and a human baseline.

## Overview
This is a Node.js Express Authentication Microservice built with TypeScript. It provides endpoints for user registration, login, and secure session management using JWTs (JSON Web Tokens) and MongoDB.

## Getting Started

### Prerequisites
- Node.js (v18 or higher)
- MongoDB running locally on port `27017`

### Installation
```bash
npm install
```

### Running the Application
To start the application in development mode (with hot-reloading):
```bash
npm run dev
```

The server will start on `http://localhost:5000`.

### API Endpoints
- **POST /api/users**: Register a new user
- **POST /api/sessions**: Login and create a new session (returns access and refresh tokens)
- **POST /api/token**: Refresh an expired access token
- **POST /api/logout**: Invalidate the current session
